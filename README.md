# Royen VVIP - Plataforma Web Oficial

Plataforma web de movilidad premium y servicios ejecutivos con estimador de tarifas inteligente, arquitectura de seguridad y app oficial.

---

## 🛠️ Tecnologías Utilizadas
- **React 19** + **TypeScript**
- **Vite**
- **Lucide Icons**
- **Google Gen AI SDK (@google/genai)**

---

## Instalación y Ejecución Local

1. Clonar el repositorio:
   \`\`\`bash
   git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   cd royenvip_web
   \`\`\`

2. Instalar dependencias:
   \`\`\`bash
   npm install
   \`\`\`

3. Iniciar el servidor de desarrollo:
   \`\`\`bash
   npm run dev
   \`\`\`
